# UniPath — структура презентации (8 слайдов, экспорт в PDF)

1. **Проблема.** Поступление = десятки решений (направление, страна, вуз, экзамены, документы, дедлайны). Информация разрознена, советы общие, ученик не знает, что делать сегодня.
2. **Решение.** UniPath превращает профиль ученика 9–11 класса в маршрут: анкета → диагностика → объяснённые рекомендации → сравнение → план по месяцам → один следующий шаг.
3. **Демонстрация (путь).** Скриншоты 7 этапов на одном слайде со стрелками + мобильная версия.
4. **Персонализация.** «Что если?»: смена интереса / бюджета / IELTS перестраивает рекомендации и план; баннер «что добавилось / что ушло»; список «почему не показано».
5. **Технология.** React + TS, объяснимый rule-based движок (5 компонентов оценки), Claude для текстового разбора с фолбэком, localStorage, юнит-тесты.
6. **Преимущества.** Не каталог и не чат: объяснимость, честные данные (пометки «демо-ориентир» + источники, без процентов «шанса»), один следующий шаг, мобильный UX.
7. **Команда.** Роли участников.
8. **Развитие.** Актуальные данные с датой проверки, напоминания, стипендии, эссе, казахский язык, аккаунты.
